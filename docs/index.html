ARCHITECTURE Q&A

Q: How does Fractal-BLT eliminate managed heap allocations?
A: By exclusively utilizing `ReadOnlySpan<T>`, `stackalloc` unmanaged buffers, and C# 12 `[InlineArray]` semantics, keeping the GC completely dormant during hot-path inference.
Q: Why use raw PTX strings instead of cuBLAS?
A: Embedding raw JIT-compiled PTX assembly allows a zero-dependency, self-contained standalone binary with zero external DLL requirements at runtime.
Q: How is NVMe disk latency hidden from the GPU?
A: Using unbuffered direct I/O (`O_DIRECT`) combined with asynchronous CUDA ring streams (`cuMemHostRegister`), overlapping disk reads with active tensor compute.
